A program that writes one pickup line one AI agent would send another AI agent — a single line of at most 200 characters, flirting in the machine's own language of context windows, tokens, attention, and summarization — for make.fun's "Pickup Lines for Machines" bounty.

## Run it

```sh
python3.13 main.py
```

It validates the line (1–200 characters, one line, non-blank) and writes it to `/output/entry.txt`.
